# MyTeam

Веб-приложение для тимлида: удобное ведение команды — сотрудники, потребности, стиль руководства, one-to-one, делегирование и обратная связь.

Данные хранятся локально в браузере (IndexedDB). Между браузерами и устройствами можно переносить базу через экспорт/импорт JSON.

## Стек

- React 19 + TypeScript
- Vite
- Ant Design
- React Router
- IndexedDB (`idb`)

## Возможности

- Список сотрудников: добавление (имя, фамилия), удаление с подтверждением
- Карточка сотрудника (`/employee/:id`) с табами:
  - **Базовые потребности** — оценка по шкале 0–5, индикаторы К/ОТ, комментарии и подсказки, радар
  - **Стиль руководства** — инструктирующий / поддерживающий / направляющий / доверяющий
  - **Заметки после One-to-one** — сохранение списком с датой и редактированием
  - **Делегирование** — заметки списком
  - **Обратная связь** — тип фидбека, модели (SBI, бутерброд, ПОПС, CARE), правила
- Светлая и тёмная тема
- Экспорт и импорт всей базы (JSON) для переноса между браузерами
- Адаптивная вёрстка под телефоны и планшеты

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:5173/MyTeam/](http://localhost:5173/MyTeam/).

## Скрипты

| Команда | Описание |
| --- | --- |
| `npm run dev` | Режим разработки |
| `npm run build` | Прод-сборка в `dist/` |
| `npm run preview` | Локальный просмотр прод-сборки |
| `npm run lint` | Проверка кода (oxlint) |

## Деплой (GitHub Pages)

Сайт публикуется автоматически при пуше в `main`:

**https://melodystic.github.io/MyTeam/**

Один раз в репозитории: **Settings → Pages → Source → GitHub Actions**.

После сборки в `dist` копируется `404.html` (fallback для React Router), `base` Vite — `/MyTeam/`.

IndexedDB привязан к домену браузера: на Pages база будет отдельной — перенесите данные кнопками **Сохранить базу** / **Загрузить базу** в шапке.
